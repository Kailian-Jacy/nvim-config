*agent-track.txt*   Shadow-ref subcommit streaming, review & sync for Neovim
*agent-track*

==============================================================================
1. INTRODUCTION & WORKFLOW          *agent-track-intro* *agent-track-workflow*

`agent-track` streams atomic shadow subcommits from a local or SSH agent
worktree (`R`) into Neovim (`L`) for causal `codediff.nvim` review and
fail-fast working-tree sync — built on Git 2.38+ plumbing with zero central
server, zero `.git/index` or `HEAD` mutation, and zero conflict markers.

Single-Writer Shadow-Ref Protocol~
Session state lives under `<ref_prefix>/<S>/` (`refs/subcommits/default/`) and
`refs/notes/<notes_prefix>/<S>` (`refs/notes/subcommits/default`):
  `base`      Common ancestor commit SHA recorded at session init.
  `agent`     Linear subcommit tip (`base..agent`) written via temp index.
  `synced`    Exact agent tree materialized into `L` (`Applied-Subcommits`).
  `approved`  Optional `1..k` prefix-approval watermark commit.
  `undo`      Lossless `commit-tree` stack of pre-sync `L` working trees.
  `state`     JSON blob `{ remote, session, applied_ids }`.
  `notes`     Per-commit JSON `{ status, comment, subcommit_id, patch_id }`.

Each subcommit carries `Subcommit-Id` (survives history rewrites; marks
previously approved commits `"stale"` if `git patch-id --stable` changes) and
`Touch-Order` (causal file reading sequence stepped with `]f` / `[f`).

`.git/index` Invariance & `walk-commit` Synergy~
`apply()` and `undo()` snapshot `L` via a temporary `GIT_INDEX_FILE`, run
in-memory `git merge-tree --write-tree`, abort cleanly (`would_conflict`)
before touching disk on any overlap, and materialize changed paths via
`git checkout-index -f` + `:checktime`. `HEAD` and `.git/index` stay untouched
until finalized into clean Git commits via `walk-commit`.
Session resolution: explicit arg -> active session -> `$AGENT_TRACK_SESSION`
-> `default_session` (`"default"`).

2. COMMANDS                               *agent-track-commands* *:AgentTrack*

`:AgentTrack` with no arguments runs `:AgentTrack status`. Tab completion
completes subcommands, discovered session names, and `sync` targets.

:AgentTrack attach {remote} [session]                  *agent-track-attach*
    *:AgentTrack-attach* Verify shared Git history with {remote} (`/path`,
    `user@host:repo`, or `ssh://[user@]host[:port]/path`), save `remote` in
    `agent-track.remote`, fetch all `<ref_prefix>/*/{base,agent}` & notes,
    auto-switch to a non-empty remote session if [session] was omitted, and
    start wildcard watcher (`fs_event` or single SSH `for-each-ref` stream).
    Then opens the first `pending`/`stale` subcommit in the `[track]` diff
    (`reviewer.open_on_attach = false` disables; Lua/RPC attach never opens).

:AgentTrack session [name]         *:AgentTrack-session* *agent-track-session*
    List discovered `<ref_prefix>/*/agent` sessions (marking active with `*`),
    or switch active session to `[name]` (initializing `base`/`synced`).

:AgentTrack init [remote]                *:AgentTrack-init* *agent-track-init*
    Initialize or activate the current session (optionally binding [remote]).

:AgentTrack detach [session]         *:AgentTrack-detach* *agent-track-detach*
    Stop background `fs_event` / poll / outbound SSH watcher.

:AgentTrack fetch [session]            *:AgentTrack-fetch* *agent-track-fetch*
    Fetch `+<ref_prefix>/*/{agent,base}` and `+refs/notes/<notes_prefix>/*`
    from the session remote, auto-switching if active session is empty and a
    task-named session has subcommits; fires |AgentTrackUpdated| on updates.

:AgentTrack status [session]         *:AgentTrack-status* *agent-track-status*
    Echo session name, remote, `synced/total`, `✓`/`·`/`✗` review counts, and
    active watcher mode (`local`, `ssh`, `poll`, or `off`).

:AgentTrack review [session]         *:AgentTrack-review* *agent-track-review*
    Open the `Snacks.picker` subcommit review panel (`vim.ui.select` fallback)
    with review badges (`✓`/`✓*`/`✗`/`~`/`·`).

:AgentTrack update                                       *:AgentTrack-update*
    Synchronously fetch every session's subcommits and review notes from
    every remote this repo knows: the active session's, each session's
    recorded remote, and `git config agent-track.remote` (deduplicated). An
    unreachable remote (e.g. a stale `/tmp` attach) is reported with `!` and
    skipped; the rest still update. Reports new sessions (`+`) and changed
    counts (`~`); never switches the active session.

:AgentTrack list [--raw]                                   *:AgentTrack-list*
    Minimal `Snacks.picker` (`vim.ui.select` fallback) of every session
    (`refs/subcommits/*/agent`): `*` active, name, `✓` approved, `✗` rejected,
    `·` pending. Listing is read-only and idempotent (local refs). While the
    picker is open a background `git ls-remote` adds sessions that exist only
    on the attached remote, marked `(remote)` (nothing is fetched). `<CR>`
    connects the session (|agent-track-connect|) and opens its review deck.
    `--raw` prints the local table to |:messages| instead.

                                                      *agent-track-connect*
    Connecting makes a session active and follows only it: a watcher on its
    `refs/subcommits/<S>/agent` and its notes ref (ssh stream or local fs
    events) fetches just that session, so new subcommits and the other side's
    comments arrive live and other sessions never switch you away. One session
    is connected at a time. Remote names such as `hg` resolve to their URL.

:AgentTrack open [idx|sha|id]            *:AgentTrack-open* *agent-track-open*
    Open target subcommit (default: first `pending`/`stale`, else latest) in
    a single reused `[track]` `:CodeDiff` tab (scratch `diff` fallback).

:AgentTrack approve [idx|sha|id] [--prefix]            *agent-track-approve*
    *:AgentTrack-approve* Mark target (or first pending/stale) `"approved"`
    and push notes. With `--prefix`, sets `<ref_prefix>/<S>/approved`
    watermark (defaults to latest subcommit `1..#items` if target omitted).

:AgentTrack reject [idx|sha|id] [reason...]             *agent-track-reject*
    *:AgentTrack-reject* Mark subcommit `"rejected"` with `[reason...]`
    comment and push review notes back to remote (`agent_track.py inbox`).

:AgentTrack sync [approved|all|{idx|sha|id}]              *agent-track-sync*
    *:AgentTrack-sync* Fail-fast 3-way merge into working tree (default
    `approved`). Supports non-prefix cherry sync when earlier subcommits are
    rejected/pending; `all` or `{idx|sha|id}` syncs prefix `1..k`. Saves
    modified buffers (`auto_save_before_sync`) and pushes onto `undo`.

:AgentTrack undo [session]               *:AgentTrack-undo* *agent-track-undo*
    Pop `<ref_prefix>/<S>/undo` to restore the exact pre-sync working tree,
    `synced` ref, and `applied_ids` without touching `.git/index`.

:AgentTrack clean [session]            *:AgentTrack-clean* *agent-track-clean*
    Detach watcher and delete session refs (`base`, `agent`, `synced`,
    `approved`, `undo`, `state`) plus `refs/notes/<notes_prefix>/<S>`.

3. KEYMAPS                            *agent-track-keymaps* *agent-track-keys*

Global Keymaps (`lua/plugins/agent-track.lua`)~
  LHS             Action ~
  `<leader>atr`   `require("agent-track.reviewer").panel()` (Review panel)
  `<leader>ato`   `require("agent-track.reviewer").open()` (`[track]` diff)
  `<leader>ats`   `:AgentTrack sync approved`
  `<leader>atu`   `:AgentTrack undo`
  `<leader>atf`   `:AgentTrack fetch`
  `<leader>ati`   `:AgentTrack status`

`[track]` `:CodeDiff` Tab Buffer-Local Keys~           *agent-track-diff-keys*
Installed in Normal mode on non-floating buffers inside the `[track]` tab
(each option takes one lhs or a list of lhs). The tab is read-only, so the
defaults are single letters; the `<leader>t*` keys remain as aliases:
  LHS                 Action (option) ~
  `<D-j>` / `<D-k>`   Next / prev subcommit, also `<leader>tj`/`tk`, `]c`/`[c`
  `J` / `K`           Next / prev `Touch-Order` file, also `]f` / `[f`
  `A`                 Approve & open next pending/stale, also `<leader>ta`
  `R`                 Reject (optional reason) & open next, also `<leader>tx`
  `m`                 Comment on line / Visual selection, also `<leader>tq`
  `b` / `c`           Toggle the file tree / the subcommit pane
  `<leader>tc`        Prompt comment, approve & open next (`approve_comment`)
  `<leader>tA`        Prefix-approve `1..current` (`approve_prefix`)
  `<leader>ts`        Sync `approved`, else `1..current` (`sync`)
  `<leader>tp`        Open `Snacks.picker` review panel (`panel`)
Options: `next_subcommit`, `prev_subcommit`, `next_touch_file`,
`prev_touch_file`, `approve`, `reject`, `comment`, `toggle_explorer`,
`toggle_pane`. They shadow `b` (word back), `c`, `J`, `K` and codediff's
explorer `R`/`K` inside the `[track]` tab only.
A subcommit opens at its `Touch-Order` #1 file; `]f`/`[f` stay in the same tab.

Line Comments~                                   *agent-track-comments*
`m` (`<leader>tq`) in a diff window comments the cursor line, or in Visual the
selected lines. Inline (and the right side of side-by-side) is the subcommit's
`new` side; the left side of side-by-side is its parent (`old`). Each comment is
appended to the note as one JSON line, so a subcommit can carry any number,
independent of approve/reject. Comments show as end-of-line virtual text
(`AgentTrackComment`), as a `💬n` count in the pane and in the `p` float.
Notes are append-only JSONL: >
  {"t":"review","status":"approved","at":...,"subcommit_id":...}
  {"t":"comment","path":"a.lua","side":"new","line":3,"end_line":5,"body":...}
<On fetch both sides' lines are merged (`git notes merge -s cat_sort_uniq`) and
notes are pushed without force. Legacy one-object notes still read.

`Snacks.picker` Review Panel Keys (Normal Mode)~     *agent-track-picker-keys*
Active in both `list` and `input` Normal mode inside `:AgentTrack review`:
  Key         Action ~
  `<CR>`      Close picker & open subcommit in `[track]` `:CodeDiff` tab
  `a` / `A`   Approve selected / Prefix-approve `1..idx`
  `C`         Prompt comment & approve selected
  `x` / `c`   Prompt reason & reject / Clear status back to `"pending"`
  `s` / `S`   Sync all `approved` / Sync prefix `1..idx` up to selected
  `u` / `r`   Undo last sync / Fetch from remote & refresh picker
  `<c-q>`     Send selected (else all) subcommits to quickfix, see below

Quickfix List~                                 *agent-track-quickfix*
`<c-q>` in the picker (Snacks `qflist`/`qflist_all`/`loclist`) builds the list
"AgentTrack [<S>]" with rows `<sha>|<index>| <status> <subject> [Touch: ...]`.
Each entry points at a placeholder `<prefix><S>/<sha>` (`g:agent_track_qf_prefix`,
default `agenttrack://`, set in `lua/config/options.lua`): `<CR>`,
`:cc`, `:cnext`/`:cprev` read it, which returns the jump window to its own
buffer and opens that subcommit in the `[track]` `:CodeDiff` tab.

Subcommit Pane~                                *agent-track-pane*
The `[track]` tab lists every subcommit in a full-width bottom split, like
`:botright copen` (explorer-style header and selection colors):
>text
   Subcommits (8)                                              ✓2 ·6
   ✓ 1 805c14b feat(codediff): show the explorer as a tree by default
   · 3 e329445 feat(agent-track): dock a subcommit pane (selected)
<
Rows: review badge (`✓` approved, `✗` rejected, `~` stale, `·` pending),
index (short SHA when >= 56 columns wide), and the truncated subject.
It stays at the bottom across `toggle_explorer`, keeps manual resizes, and
stays closed after `:q` in that tab. `position = "explorer"` docks it under
the file tree instead (hides/returns with the explorer). Keys:
  `<CR>` / `o`    Open the subcommit under the cursor
  `p`             Float with the full message, body and review comment
  `A`/`a`, `R`/`x` Approve / Reject the row under the cursor
  `C`             Approve the row with a comment
  `m`             Subcommit-level comment on the row
  `r`             Re-list (automatic on `AgentTrack{Updated,Reviewed,Synced}`)
Options: `reviewer.pane = { enabled, position = "bottom", max_height = 5 }`.
Highlights:
`AgentTrackPane{Header,Current,Dim}` (links: `CodeDiffExplorerTreeGroup`,
`CodeDiffExplorerSelected`, `Comment`).

4. AUTOCMDS & HOOKS                                     *agent-track-autocmds*

`agent-track` emits `User` autocmds (`modeline = false`) and invokes matching
`setup({ hooks = ... })` callbacks with the exact same `ev.data` table:

*AgentTrackUpdated*  (`hooks.on_updated(data)`)
    Fired by `fetch()` when `<ref_prefix>/<S>/agent` changes to a new SHA.
    `ev.data`: `{ session = string, agent = string, previous = string|nil }`
    (`previous` is `nil` on initial arrival).

*AgentTrackReviewed*  (`hooks.on_reviewed(data)`)
    Fired by `review()` after recording a review note or `--prefix` watermark.
    `ev.data`: `{ session = string, sha = string, status = string,
    prefix = boolean }` (`status`: `"approved"` | `"rejected"` | `"pending"`).

*AgentTrackSynced*  (`hooks.on_synced(data)`)
    Fired by `apply()` (when not `noop`) and by `undo()` on clean completion.
    `apply()` `ev.data`: `{ session = string, synced = string, clean = true }`
    `undo()`  `ev.data`: `{ session = string, undo = true, synced = string }`
    (`synced` is the new or restored `<ref_prefix>/<S>/synced` commit SHA).
>lua
  vim.api.nvim_create_autocmd("User", {
    pattern = { "AgentTrackUpdated", "AgentTrackReviewed",
                "AgentTrackSynced" },
    callback = function(ev) vim.print(ev.match, ev.data) end,
  })
<
Internal Lifecycle Autocmds~
  `VimLeavePre` (`AgentTrackWatchCleanup`) Detaches watchers & SSH streams.
  `User CodeDiffOpen` (`once = true`)      Tags `ev.data.tabpage` `[track]`.
  `BufEnter` (`AgentTrackReviewer`)        Scoped to `vim.t.agent_track_tab`;
                                         keeps `t:tabname` & buffer keymaps.
  `WinNew`/`WinClosed`/`TabClosed`/        (`AgentTrackPane`) Keeps the subcommit
  `WinResized` + the 3 `User` events      pane in place (bottom/explorer) & fresh.

5. CONFIGURATION & STATUSLINE       *agent-track-config* *agent-track-setup*
                                    *agent-track-statusline*
>lua
  require("agent-track").setup({
    ref_prefix = "refs/subcommits", notes_prefix = "subcommits",
    default_session = "default", git_cmd = { "git" },
    ssh_cmd = {
      "ssh", "-o", "BatchMode=yes", "-o", "ControlMaster=auto",
      "-o", "ControlPath=/tmp/at-ssh-%C", "-o", "ControlPersist=600",
      "-o", "ServerAliveInterval=30",
    },
    watch = {
      enabled = true, mode = "auto", -- "auto" | "local" | "ssh" | "poll"
      poll_ms = 5000, ssh_poll_ms = 0, debounce_ms = 150,
      reconnect_ms = 3000, max_retries = 3,
      remote_tail_cmd = nil, -- string | string[] | fun(remote, session)
    },
    auto_save_before_sync = true, auto_sync_approved = false,
    notify_on_arrival = true,
    reviewer = {
      tab_prefix = "[track]", reuse_tab = true, open_on_attach = true,
      pane = { enabled = true, position = "bottom", max_height = 5 },
      keymaps = { -- each value: one lhs or a list of lhs
        next_subcommit = { "<D-j>", "<leader>tj", "]c" },
        prev_subcommit = { "<D-k>", "<leader>tk", "[c" },
        next_touch_file = { "J", "]f" }, prev_touch_file = { "K", "[f" },
        approve = { "A", "<leader>ta" }, approve_comment = "<leader>tc",
        approve_prefix = "<leader>tA", reject = { "R", "<leader>tx" },
        comment = { "m", "<leader>tq" }, sync = "<leader>ts",
        panel = "<leader>tp", toggle_explorer = "b", toggle_pane = "c",
      },
    },
    statusline = { enabled = true, format = nil },
    hooks = { on_updated = nil, on_synced = nil, on_reviewed = nil },
  })
<
`statusline()` returns `"[track <synced>/<total> ·<pending>]"` (or
`"[track:<S> idle]"` when attached with 0 subcommits, else `""`).
`statusline.format(info)` gets `{ session, remote, total, synced, pending }`.
Highlights: `AgentTrack{Approved,Rejected,Stale,Pending,Synced,Conflict}`,
`AgentTrackPane{Header,Current,Dim}` (|agent-track-pane|).

6. LUA API & GRANTSOCKET RPC              *agent-track-api* *agent-track-rpc*

Lua Module (`local at = require("agent-track")`)~
  `at.setup(opts)` / `at.get_config()` / `at.statusline()`
  `at.attach(remote, opts)` / `at.init_session(remote_or_opts, opts)`
  `at.session(name, opts)` / `at.sessions(opts)`
  `at.detach(session)` / `at.fetch(session, opts)` / `at.status(session)`
  `at.list(session, { preview_conflicts = bool })`
  `at.review(sha_or_idx, status, { comment, prefix, push, session })`
  `at.apply(target, { mode = "prefix"|"cherry", session })`
  `at.undo(session, opts)` / `at.clean(session, opts)`
  `require("agent-track.reviewer")`: `panel(opts)`, `open(target, opts)`,
  `close()`, `status()`, `next/prev_subcommit()`, `next/prev_touch_file()`,
  `qflist(items, { session, win })` (|agent-track-quickfix|).
  `require("agent-track.pane")`: `show(tab, { session, root, sha, items })`,
  `refresh(tab?)`, `get(tab?)` (|agent-track-pane|).

`:GrantSocket` RPC (`require("agent-track").rpc.dispatch(req)`)~
Accepts JSON string or table `{ method = "<name>", args = { ... } }` and
returns JSON `{"ok":true,"result":...}` or `{"ok":false,"error":"..."}`.
Methods: `ping` (`info`), `init` (`init_session`), `attach`, `detach`,
`session`, `sessions`, `fetch`, `status`, `list`, `review`, `approve`,
`reject`, `apply` (`sync`), `undo`, `clean`, `open`, `panel`, `close`.
>sh
  nvim --server "$SOCK" --remote-expr \
    'luaeval("require(\"agent-track\").rpc.dispatch(_A)",
             "{\"method\":\"list\"}")'
